# DX3rd → ココフォリア変換ツール

ゆとシートII for DX3rd のキャラクターシートから、ココフォリアにコピペで登録できるJSONコードを生成する静的Webアプリです。

## 使い方

1. キャラクターシートのURLを入力して「取得」をクリック
2. CORS制限で取得できない場合は、URLの末尾に `&mode=json` を追加してブラウザで開き、表示されたJSONをコピーして貼り付け
3. 「変換」をクリック
4. 出力された「ココフォリア コピペ用コード」をコピーし、ココフォリアの盤面上で Ctrl+V で貼り付け

## 生成される内容

### キャラクターコマ
- ステータス（HP、侵蝕率、ロイス、財産、攻撃力、ガード、装甲値）
- パラメータ（能力値4種、技能、侵蝕率自動計算用パラメータ）
- キャラクター画像・シートURL連携

### チャットパレット
- **登場**：登場ダイス、侵蝕率・HP操作
- **技能判定**：全能力値×技能の判定式（侵蝕率ダイス自動補正付き）
- **復活**：リザレクト、タイタス昇華
- **ロイス一覧**：Dロイス・ロイス（名前のみ送信 / 感情・備考付き送信）
- **セットアップ／マイナー／オート**：各エフェクトの侵蝕率コスト・効果
- **コンボ**：侵蝕率コスト・効果説明・判定式・ダメージ式（攻撃型コンボのみ）

### 侵蝕率による自動計算
BCDiceの整数除算を利用して、侵蝕率に応じた以下の補正を自動で反映します。

- **侵蝕率ダイス**：判定ダイスの増加（0〜+4）
- **侵蝕率Lv**：エフェクトレベルの上昇（0〜+2）
- **コンセ**：コンセントレイトのC値追加低下（下限7考慮）
